Класс EmailMessage создается, чтобы хранить информацию об одном письме. Далее создается конструктор класса и он вызывается когда мы создаем новое письмо, в скобках передаются данные письма. Далее сохраняется имя файл письма (mail_001.txt), далее сохраняется полный текст письма т.е все содержимое файла, тема письма и отправитель письма.
