#Описание класса
В данной части кода реализуется класс MailClassifier. Класс нужен для определения категории входящих писем и автоматического распределения их по папкам с соответствующими категориями: 1) доступы (access): письма, связанные с предоставлением доступа, прав или решения проблем со входом в личный кабинет; 2) финансы (finance): письма, связанные со счетами и договарами для оплаты услуг; 3) hardware: письма, сообщающие о проблемах с "железом" и плановыx мониторингах; 4) важное (important): письма, требующие срочного ответа или действия, сообщающие о критических инцидентах, ситуациях, когда работа не может продолжаться; 5) входящие (inbox): входящие письма, не несущие особенной информации, инструкции, выполненные задания, дайджесты или по ошибке отправленные письма; 6) спам (spam): письма, сообщающие о выигрыше розыгрыше и эксклюзивных акциях. Классификация происходит по принципу ключевых слов с дополнительными исключениями для пограничных случаев.
#Структура класса
Метод __init__(self)
Реализуется словарь self.rules: ключ - название категории, значение - список ключевых слов. Категории проверяются в том порядке, в котором они перечислены в словаре.
Метод classify (self, subject, sender, body) -> str
Принимает тему, отправителя и текст письма, возвращает название категории плану: 1) Формирование строки; 2) Перебор категорий и ключевых слов; 3) Проверка на исключения для important, чтобы отфильтровать неинформативные сообщения; 4) Возвращение первой подходящей категории; 5) Если ни одна из категорий не подошла, сообщение остается во входящих;
