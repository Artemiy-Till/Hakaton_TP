__Описание класса MailClassifier__

В данной части кода реализуется класс MailClassifier. Класс нужен для определения категории входящих писем и автоматического распределения их по папкам с соответствующими категориями:  
1) доступы (access): письма, связанные с предоставлением доступа, прав или решения проблем со входом в личный кабинет;
2) финансы (finance): письма, связанные со счетами и договарами для оплаты услуг;
3) hardware: письма, сообщающие о проблемах с "железом" и плановыx мониторингах;
4) важное (important): письма, требующие срочного ответа или действия, сообщающие о критических инцидентах, ситуациях, когда работа не может продолжаться;
5) входящие (inbox): входящие письма, не несущие особенной информации;
6) инфо (info): дайджесты, напоминания, приглашения;
7) документы (docs): инструкции и правки;
8) спам (spam): фишинг, спам, рекламные акции.

Классификация происходит по принципу ключевых слов с дополнительными исключениями для пограничных случаев.
  
__Структура класса MailClassifier__  

- Метод __ init __(self)  
Реализуется словарь self.rules: ключ - название категории, значение - список ключевых слов. Категории проверяются в том порядке, в котором они перечислены в словаре.  
- Метод classify (self, subject, sender, body) -> str  
Принимает тему, отправителя и текст письма, возвращает название категории плану:   
1) Формирование строки;  
2) Перебор категорий и ключевых слов;
3) Проверка на исключения для important, чтобы отфильтровать неинформативные сообщения;
4) Возвращение первой подходящей категории;
5) Если ни одна из категорий не подошла, сообщение остается во входящих;

__Описание класса FileManager__  

FileManager - это класс для работы с файлами в проекте.
Он отвечает за:
- создание папки output;
- создание папки broken_files;
- перемещение обработанных писем в папки категорий;
- перемещение плохих файлов в папку broken_files.

__Структура класса FileManager__  

- При создании объекта FileManager проверяет, есть ли папки:
-output
-broken_files
Если таких папок нет, он создаёт их.

- Метод move_file   
Нужен для перемещения обычного обработанного письма из папки inbox в папку нужной категории внутри output.
Метод принимает два аргумента:
file_path - путь к файлу, который нужно переместить;
category - категория, в которую нужно положить файл.
Затем создает путь к папке той категории, в которую мы будем заносить файл.
Дальше проверяет, существует ли уже такая папка, если нет, создает.
Далее берет из пути файла только его название, создает новый путь к файлу и с помощью rename перемещает из папки inbox в папку нужной категории в папке output.
Возвращает путь к файлу в новой папке

- Метод move_broken_file  
Метод move_broken_file нужен для плохого файла из папки inbox в папку broken_files.
Метод принимает один аргумент:
file_path - путь к файлу, который нужно переместить.
Далее берет только имя из пути файла с помощью функции os.path.basename
и делает новый путь к файлу, который уже будет лежать в папке broken_files. И 
с помощью rename перемещает файл из папки inbox. 
Возвращает путь к файлу в новой папке

__Описание класса MailReader__  

class MailReader отвечает за чтение письма и должен доставать из него отправителя и тему письма. Внутри реализовано 4 метода.

__Структура класса MailReader__

- Метод read
На вход он принимает название письма, с помощью метода imageMessage определяет, не картинка ли это. То есть если строка названия письма заканчивается на один из видов формата фото-изображений - выбрасывается ошибка ValueError. Также добавлена проверка на пустоту файла, которая в случае пустоты выбрасывает ValueError
Далее метод проверяет, файл ли был подан на входе, если файл - то пробует его открыть и извлечь текст, если не получилось - бросает ошибку ValueError. Если входные данные оказались не файлом - метод выбросит ошибку ValueError
- Методы findSender и findSubject
findSender разбивает извлеченный текст письма на строки, затем обрабатывает начало строки и если находит слова "From:", "Ot kogo:", "От кого", то возвращает отправителя письма. findSubject также разбивает извлеченный текст письма на строки и проверяет начало каждой строки. Если встречаются "Тема", "Subject", "Tema", то метод возвращает тему письма.

В итоге метод возвращает переменную типа EmailMessage. Класс MailReader помогает дальнейшей обработке писем, чтобы разложить их по разным папкам, так как по теме письма или отправителю некоторые письма сразу можно отправить в ту или иную папку
