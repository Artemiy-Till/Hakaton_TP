# Hakaton_TP
class MailReader отвечает за чтение письма и должен доставать из него отправителя и тему письма. Внутри реализовано 4 метода:
1. read. на вход он принимает название письма, с помощью метода imageMessage определяет, не картинка ли это. То есть если строка названия письма заканчивается на один из видов формата фото-изображений - выбрасывается ошибка ValueError. Также добавлена проверка на пустоту файла, которая в случае пустоты выбрасывает ValueError
Далее метод проверяет, файл ли был подан на входе, если файл - то пробует его открыть и извлечь текст, если не получилось - бросает ошибку ValueError. Если входные данные оказались не файлом - метод выбросит ошибку ValueError
Затем используются методы findSender и findSubject. findSender разбивает извлеченный текст письма на строки, затем обрабатывает начало строки и если находит слова "From:", "Ot kogo:", "От кого", то возвращает отправителя письма. findSubject также разбивает извлеченный текст письма на строки и проверяет начало каждой строки. Если встречаются "Тема", "Subject", "Tema", то метод возвращает тему письма.
В итоге метод возвращает переменную типа EmailMessage. Класс MailReader помогает дальнейшей обработке писем, чтобы разложить их по разным папкам, так как по теме письма или отправителю некоторые письма сразу можно отправить в ту или иную папку
