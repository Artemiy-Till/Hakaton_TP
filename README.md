Первая строка кода показывает что файл это баш-скрипт и команды выполняются через баш. Далее выводим в терминал сообщение о том что проект начал запускаться и переводим терминал в папку где лежит файл run.sh, чтобы скрипт правильно находил папки инбокс, срс, логс. Дальше проверяем есть ли папка inbox, т.е если папки нет, то выполняется команда ниже и выводится сообщение об ошибке, что папка инбокс не найдена, из-за этого скрипт останавливется с ошибкой, потому что без папки программа не сможет обрабоать письма и это конец проверки.
Далее проверяется есть ли главный файл мэин, если файла нет скрипт не запускает программу дальше и выводит ошибку что мэин не найден. это конец второй проверки.
Далее проверяем есть ли папка логс, в нее будет сохраняться вывод программы, если ее нет, то она создается (mkdir logs), это конец проверки папки логс
Далее выводится сообщение что папка с письмами найдена и что мэин файл тоже найден. Далее скрипт пишет, что начинрает заауск питон программы.
python src/main.py,строка запускает файл срс мэин, и далее запускается питон программа. 
> logs/run_output.log сохраняет обычный вывод программы в файл логс, 2>&1 сохраняет ошибки туда же в лог файл, если программа упадет, то причин будет тоже записана в логс.
if [ $? -eq 0 ]; then проверяет успешно ли завершилась программа, т е хранит последнюю комнду и если там 0 то все прошло без ошибок
далее выводится сообщение об успешном завершении и скрипт сообщает где лежит результат программы
после else условие на случай если программа завершилась с ошибкой, скрипт показывает где можно посмотреть подробности об ошибке и завершается с 1. это конец.
